# 航班中断公告收敛中心

负责中断公告、订阅投递与接收回执的可靠流转。服务只提供 HTTP API，不包含网页或浏览器客户端。

## 工程结构

应用入口负责进程启动和健康检查，领域代码与存储适配器保持独立目录。运行参数由环境变量提供，时间值统一使用 ISO 8601 格式，接口错误返回 JSON。

## 容器运行

执行 `docker compose up --build -d`，等待服务启动后以 `curl http://localhost:8080/health` 检查运行状态；结束时执行 `docker compose down`。

## 本地检查

依赖安装和测试命令记录在对应语言的项目清单中。健康接口返回 `status` 与 `service`，可用于容器探针和自动化检查。
